# Account Settings and Profile Updates

Use **Settings → Profile** to change your display name, notification preferences, locale, and other non-sensitive profile details. Changes are saved immediately after you select **Save changes**.

If you need to change the sign-in email and your account supports email changes, use **Settings → Security → Email**. A verification message is sent to the new address before the change is finalized.

For security-sensitive account changes that you did not initiate, do not continue with normal profile steps; use the account-compromise guidance instead.
